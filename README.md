# UI 용어 사전

화면 만들 때 쓰는 UI 용어 156개를 그림과 한 줄 설명으로 정리한 단일 HTML 페이지입니다.

- 사이트: https://ug.sanghak.kr
- 파일: `index.html`(사전), `privacy.html`(개인정보처리방침), `manifest.json` + `sw.js`(PWA). GitHub Pages로 배포
- Firebase: Analytics, Google 로그인(Auth)
